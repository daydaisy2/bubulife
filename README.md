# Bubulife 🏡

세은과 찬규가 함께 쓰는 **공동 할 일 · 가족 일정 대시보드**입니다.
휴대폰 홈 화면에 설치해 앱처럼 쓸 수 있는 PWA(Progressive Web App)입니다.

## 여는 방법

비공개 방 링크로만 열립니다. 주소 뒤에 `?room=` 방 키가 있어야 하고,
키가 없으면 안내 화면만 보입니다.

```
https://daydaisy2.github.io/bubulife/?room=<비공개 방 키>
```

방 키는 저장소에 적지 않습니다. 링크를 아는 두 사람만 같은 목록을 봅니다.

## 무엇이 되나요

- **할 일** — 담당(세은/찬규/같이), 분류(결혼·신혼/집안일/장보기/기타), 마감일 D-day, 별표, 메모.
  추가·수정·삭제·완료 체크, 담당자별·상태별 필터.
- **캘린더** — 월/주/일 보기. 일정(제목·날짜·시간·종일·담당·장소·메모) 추가·수정·삭제.
  날짜를 누르면 그 날 일정과 마감 할 일을 함께 봅니다.
- **실시간** — Firebase Realtime Database에 저장하고 SSE로 즉시 동기화합니다.
  두 사람이 동시에 열어 두고 한쪽에서 체크하면 다른 쪽 화면이 바로 바뀝니다.
- **알림** — 브라우저 알림을 켜면 오늘 일정(30분 전)과 오늘 마감 할 일을 알려줍니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 전체 (HTML + CSS + JS 한 파일) |
| `manifest.webmanifest` | 앱 이름·아이콘·설치 설정 |
| `sw.js` | 서비스워커 (오프라인에서도 마지막 화면 열림) |
| `icon-*.png` | 앱 아이콘 (192/512, 마스커블 포함) |
| `robots.txt`, `noindex` 메타 | 검색 노출 차단 |

## 배포

`main` 브랜치와 같은 커밋을 `gh-pages` 브랜치로 올리면 GitHub Pages에 반영됩니다.
