# 부부 할일 🌼 (Bubulife)

세은과 찬규의 **오늘 할 일**만 남긴 초간단 보드입니다.
노란 바탕에 **세은 카드 · 찬규 카드** 두 장, 그게 전부입니다.
휴대폰 홈 화면에 설치해 앱처럼 쓸 수 있는 PWA입니다.

## 여는 방법

비공개 방 링크로만 열립니다. 주소 뒤에 `?room=` 방 키가 있어야 하고,
키가 없으면 방 코드를 넣는 안내 화면이 보입니다.

```
https://daydaisy2.github.io/bubulife/?room=<비공개 방 키>
```

방 키는 저장소에 적지 않습니다. 링크를 아는 두 사람만 같은 목록을 봅니다.

## 무엇이 되나요

- **폰 세로 화면은 위/아래 절반** — 세은 카드가 위 절반, 찬규 카드가 아래 절반을 딱 나눠 가지며,
  화면 전체가 한 뷰포트(`100dvh`)에 들어갑니다. 카드마다 할 일 목록만 따로 스크롤되고
  `+ 할 일 추가` 버튼과 완료됨 바는 늘 같은 자리에 있습니다. 가로·넓은 화면은 2열 유지.
- **큰 추가 버튼** — 카드 아래에 폭을 꽉 채운 `+ 할 일 추가` 버튼(높이 50px 안팎). 누구 카드에서 눌렀는지가 담당자로 바로 잡힙니다.
- **담당자 아이콘** — 이모지를 고르지 않습니다. 할 일 항목 왼쪽 아이콘은 담당자를 따라갑니다. 세은 항목은 👩🏻, 찬규 항목은 👨🏻 (카드 헤더 아바타와 같은 아이콘). 추가·수정 시트의 미리보기도 선택한 담당자 아이콘으로 바뀝니다.
- **진행률** — 카드마다 완료 개수(`2/4`)와 진남색 진행 바.
- **완료는 따로** — 체크한 항목은 카드에서 빠지고 화면 아래 `✅ 완료됨 N` 바에 모입니다.
  바를 누르면 아래에서 시트가 올라와 연두색 + 취소선 + 초록 체크로 보이고, 체크를 다시 누르면 할 일로 돌아가고 ✕ 를 누르면 지워집니다.
- **수정·삭제** — 항목을 누르면 시트가 열립니다. 제목·담당자를 고치고 저장하거나,
  시트 아래 큼직한 `🗑 이 할 일 삭제` 를 두 번 눌러 지웁니다(한 번 누르면 확인 단계).
- **옆으로 밀어 메모·수정·삭제** — 항목을 왼쪽으로 밀면 오른쪽에 `📝 메모` · `✏️ 수정` · `🗑 삭제` 세 버튼이 드러납니다.
  바로 누르면 각각 메모 시트가 열리거나, 수정 시트가 열리거나, 그 자리에서 지워집니다.
  다른 항목을 밀거나 바깥을 탭하면 열려 있던 것은 저절로 닫힙니다.
- **메모** — 메모 시트에서 적은 내용은 `todos/{id}/note` 에 저장되고 상대 화면에도 바로 보입니다.
  메모가 있는 항목은 할 일 줄 아래 `📝 메모 내용` 한 줄로 표시됩니다.
- **드래그로 순서 바꾸기** — 마우스는 항목을 끌면 바로, 휴대폰은 항목을 살짝 길게 눌러(280ms) 잡은 뒤 위아래로 끌면 순서가 바뀝니다.
  옆으로 미는 동작(|dx| > |dy|)은 스와이프로, 위아래로 움직이는 동작은 순서 바꾸기/스크롤로 나뉩니다.
  목록 끝에 가까워지면 목록이 저절로 스크롤됩니다. 바뀐 순서(`order`)는 바로 Firebase에 저장되어 상대 화면에도 실시간으로 반영됩니다.
- **실시간** — Firebase Realtime Database에 저장하고 SSE로 즉시 동기화합니다. 한쪽에서 체크하면 다른 쪽 화면이 바로 바뀝니다.

## 파일

- `index.html` — 화면·동작 전부 (한 파일)
- `sw.js` — 오프라인 캐시 서비스워커 (`bubu-v7`). 화면은 네트워크 우선, 나머지는 캐시 우선
- `manifest.webmanifest`, `icon-*.png` — 홈 화면 설치용

## 손보는 법

`main` 브랜치를 고쳐 푸시한 뒤 같은 내용을 `gh-pages` 로도 올리면 1~2분 안에 반영됩니다.
화면 캐시가 남아 있으면 서비스워커 캐시 이름(`bubu-v7`)을 한 단계 올려 주세요.
