# 우리 할 일 🌼 (Bubulife)

세은과 찬규의 **오늘 할 일**만 남긴 초간단 보드입니다.
노란 바탕에 **세은 카드 · 찬규 카드** 두 장, 그게 전부입니다.
휴대폰 홈 화면에 설치해 앱처럼 쓸 수 있는 PWA입니다.

## 여는 방법

비공개 방 링크로만 열립니다. 주소 뒤에 `?room=` 방 키가 있어야 하고,
키가 없으면 방 코드를 넣는 안내 화면이 보입니다.

```
https://daydaisy2.github.io/bubulife/?room=<비공개 방 키>
```

방 키는 저장소에 적지 않습니다. 링크를 아는 두 사람만 같은 목록을 봅니다.

## 무엇이 되나요

- **두 카드** — `세은` 카드와 `찬규` 카드가 가로 2열로 나란히. 휴대폰 세로 화면에서도 2열을 유지합니다.
- **진행률** — 카드마다 완료 개수(`2/4`)와 진남색 진행 바.
- **할 일 줄** — 큰 이모지 + 굵은 제목 + 오른쪽 동그란 체크 원. 제목을 누르면 그 자리에서 수정·삭제.
- **완료** — 체크하면 줄 배경이 연두색으로 바뀌고 제목에 초록 취소선, 오른쪽 원이 진한 초록 체크로 바뀝니다.
- **드래그로 순서 바꾸기** — 마우스는 항목을 끌면 바로, 휴대폰은 항목을 살짝 길게 눌러 잡은 뒤 위아래로 끌면 순서가 바뀝니다.
  바뀐 순서(`order`)는 바로 Firebase에 저장되어 상대 화면에도 실시간으로 반영되고, 새로고침해도 그대로입니다.
- **추가** — 오른쪽 위 `+ 추가`(마지막에 고른 사람) 또는 카드 아래 `+ 추가`(그 사람). 담당·이모지·제목을 고르고 저장합니다.
- **실시간** — Firebase Realtime Database에 저장하고 SSE로 즉시 동기화합니다. 한쪽에서 체크하면 다른 쪽 화면이 바로 바뀝니다.

## 파일

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 전체 (HTML + CSS + JS 한 파일) |
| `manifest.webmanifest` | 앱 이름·아이콘·설치 설정 |
| `sw.js` | 서비스워커 (오프라인에서도 마지막 화면 열림) |
| `icon-*.png` | 앱 아이콘 (192/512, 마스커블 포함) |
| `robots.txt`, `noindex` 메타 | 검색 노출 차단 |

## 배포

`main` 브랜치와 같은 커밋을 `gh-pages` 브랜치로 올리면 GitHub Pages에 반영됩니다.
