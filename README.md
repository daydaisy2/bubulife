# 부부 할일 🌼 (Bubulife)

세은과 찬규의 **오늘 할 일**만 남긴 초간단 보드입니다.
노란 바탕에 **💪 운동 · 👩🏻 세은 · 👨🏻 찬규** 세 칸 탭, 하단에서 오가며 고른 화면이 전체 높이를 넓게 씁니다.
휴대폰 홈 화면에 설치해 앱처럼 쓸 수 있는 PWA입니다.

## 여는 방법

비공개 방 링크로만 열립니다. 주소 뒤에 `?room=` 방 키가 있어야 하고,
키가 없으면 방 코드를 넣는 안내 화면이 보입니다.

```
https://daydaisy2.github.io/bubulife/?room=<비공개 방 키>
```

방 키는 저장소에 적지 않습니다. 링크를 아는 두 사람만 같은 목록을 봅니다.

## 무엇이 되나요


- **헤더 한 줄** — 제목 오른쪽에 `세은 방금 / 찬규 기록 없음` 접속 시간 알약(탭하면 이 기기 프로필 바꾸기), 📣 확인 요청 공유, ✅ 완료됨, 📝 수정 요청 메모, 🔒 다시 잠그기가 같은 크기·톤의 둥근 버튼으로 나란히 있습니다. 390px 좁은 화면에서도 한 줄에 들어갑니다.
- **하단 3탭 `💪 운동` / `👩🏻 세은` / `👨🏻 찬규`** — 한 번에 한 화면만 전체 높이를 넓게 씁니다(위/아래 절반 분할은 없어졌습니다).
  첫 번째 `💪 운동` 탭은 `세은 운동`(`daydaisy2/workout-quest`)을 그대로 합친 것입니다(아래 💪 운동 탭 참고).
  `👩🏻 세은` / `👨🏻 찬규` 탭에서는 각 사람의 할 일 카드가 열리고, 그 기기 프로필(`bubu.me.v1`)의 탭이 처음 열립니다.
  활성 탭은 진남색 바탕 + 노란 글씨, 나머지는 흰 바에 회색 글씨이며, 바꿀 때 화면이 살짝 올라오며 바뀝니다.
- **💪 운동 탭** — 세은 님의 아침·저녁 운동 루틴을 이 앱 안으로 옮겼습니다.
  맨 위 요약 카드(`3/12 완료`, 진도 바, `11월 20일 금요일 · 운동 12개`, `↻ 오늘 리셋`) 아래에
  `1세트(💪)` · `2세트(🔥)` · `3세트(✨)` 각 3개 + `스트레칭(🌙)` 하체 2개 + `마무리 케어(💆)` `마스크팩 & 립밤` 카드가 있습니다.
  유튜브 섬네일을 누르면 새 탭에서 영상이 열리고, 본문을 누르면 그 자리에서 체크/해제됩니다(카드별 완료 수·진도 바 포함).
  체크 기록은 원래 앱과 같은 `localStorage` 키 `seeuni.workout-quest.v1` 에 그대로 쌓이고(같은 주소라 기존 기록이 이어집니다),
  날짜가 바뀌면 오늘 운동이 자동으로 새로 시작되며 지난 날은 `history` 에 7일만 남습니다(원래 앱과 같은 규칙).
  운동 탭에서는 `+ 할 일 추가` 와 헤더 `✅` 를 감춰 운동 화면만 깔끔하게 보입니다.
  앱을 열면 이 기기 프로필(`bubu.me.v1`)의 탭이 먼저 열리고, 그 뒤로는 하단 탭으로 언제든 자유롭게 오갑니다(탭을 바꾼 기억은 남기지 않습니다).
  활성 탭은 진남색 바탕 + 노란 글씨, 나머지는 흰 바에 회색 글씨이며, 바꿀 때 카드가 살짝 올라오며 바뀝니다.
- **+ 할 일 추가 (하단 노란 큰 버튼)** — 하단 탭 바 바로 위에 카드 폭 전체로 놓인 노란 버튼입니다.
  지금 보고 있는 탭의 사람(`seeun` / `chankyu`)으로 추가 시트가 바로 열리고, 새로 넣은 할 일은 **같은 그룹의 마지막 매주 반복 항목 바로 아래**에 들어갑니다(오늘 요일을 골라 `today` 로 저장되면 오늘할일 그룹, 고른 요일이 있으면 그 요일 그룹, 요일 없는 보통 할 일은 일반 그룹). **🗓️ 이후**로 넣으면 그 담당자 목록의 맨 끝(`order = 가장 큰 order + 1`)에 저장됩니다.
  시트에서 담당자를 바꿔 넣으면 그 사람 탭으로 넘어가 방금 넣은 항목을 보여 줍니다.
- **담당자 아이콘** — 이모지를 고르지 않습니다. 할 일 항목 왼쪽 아이콘은 담당자를 따라갑니다. 세은 항목은 👩🏻, 찬규 항목은 👨🏻 (카드 헤더 아바타와 같은 아이콘). 추가·수정 시트의 미리보기도 선택한 담당자 아이콘으로 바뀝니다.
- **진행률** — 카드마다 완료 개수(`2/4`)와 진남색 진행 바.
- **오늘 한 일은 그날은 목록에** — 완료 동그라미를 누르면 `done: true` · `doneAt` · **`doneDate`(한국 날짜)** 가 저장되고, 그 항목은 **그날은 목록에 그대로 남습니다**(제목 취소선 + 초록 체크).
  `오늘할일` 바로 아래 `오늘 완료` 자리에 모여 오늘 뭘 했는지 한눈에 보이고, 동그라미를 다시 누르면 바로 되돌아갑니다.
  날짜가 바뀌면(자정을 넘기거나 다음 날 앱을 열면) 어제 이전에 끝낸 항목은 목록에서 빠져 **`✅ 완료됨` 시트**로 넘어갑니다(`doneDate` 가 없는 예전 완료 항목도 여기에서 보입니다).
  체크하지 않은 일은 날짜가 바뀌어도 그대로 남고, 매주 반복 항목은 반복 요일이 오면 다시 살아납니다.
  `✅` 버튼을 누르면 완료됨 시트가 올라오고, 체크를 다시 누르면 목록으로 돌아오고 ✕ 를 누르면 지워집니다.
- **한 번 탭하면 메모 · 수정 시트** — 항목 본문(글자·카드)을 한 번 누르면 시트가 올라오며 메모 입력란에 바로 커서가 놓입니다.
  같은 자리에서 제목과 담당자만 고치고 `저장` 하거나, 시트 아래 `🗑 이 할 일 삭제` 를 두 번 눌러 지웁니다(한 번 누르면 확인 단계).
  왼쪽 동그라미(✓)는 그대로 완료 체크입니다.
- **왼쪽으로 밀면 삭제 버튼 하나만** — 항목을 왼쪽으로 밀면 오른쪽에 빨간 `🗑 삭제` 버튼 하나만 큼직하게(76~88px) 드러납니다.
  바로 누르면 그 자리에서 지워집니다. 오른쪽으로 밀면 닫힙니다. 다른 항목을 밀거나 바깥을 탭하면 열려 있던 것은 저절로 닫힙니다.
  휴대폰(안드로이드 크롬·PWA)에서는 `touch-action: pan-y` + `touchstart/touchmove/touchend` 로
  손가락 제스처를 직접 잡아, 브라우저가 스크롤·뒤로가기로 가져가며 `pointercancel` 을 쏘지 않게 했습니다.
- **목록 순서(자동 정렬)** — 목록은 늘 다섯 자리로 나뉘어 보입니다.
  ① **오늘할일**(`today: true`)이 맨 위, ② **오늘 완료한 일**(`doneDate` = 오늘, 취소선), ③ **요일 지정 항목**이 그 아래 **월 → 화 → 수 → 목 → 금 → 토 → 일** 순서로,
  ④ 요일 없는 **일반** 항목, ⑤ **🗓️ 이후**가 제일 밑입니다.
  요일 그룹은 여러 요일을 고른 항목이면 그중 **가장 앞선 요일**(예: `월수금` → 월 그룹, `주말` → 토 그룹)로 정해집니다.
  그룹 안에서는 `order` 오름차순이라, `오늘할일` 을 켜면 그 항목이 맨 위 그룹으로 올라가고 끄면 제 요일(요일이 없으면 일반) 그룹으로 내려갑니다. 반복 요일로 `오늘할일` 이 저절로 켜질 때도 같습니다.
  순서 편집기(`⇅`)도 같은 4단·요일 순서로 열리고, ▲▼·드래그는 그룹(같은 요일) 경계를 넘지 않습니다(그룹 안 순서만 바뀌고 `order` 로 저장).
- **오늘할일 알약** — 할 일마다 줄 맨 오른쪽, 완료 동그라미 바로 왼쪽에 `오늘할일` 알약이 붙습니다. 누르면 진남색으로 켜지고 `todos/{id}/today` 로 저장되어 상대 화면에도 바로 보입니다(오늘 할 일로 표시). 제목이 길면 제목 칸 안에서 여러 줄로 늘어나고, 알약은 오른쪽 자기 자리를 지킵니다.
- **📣 확인 요청 공유** — 헤더의 크림색 📣 버튼을 누르면 상대에게 보낼 한 줄과 앱 링크를 바로 건넵니다.
  이 기기 프로필이 세은이면 `찬규야, 부부 할일 확인해 줘! 💛`, 찬규면 `세은아, 부부 할일 확인해 줘! 💛`, 프로필을 아직 고르지 않았으면 `부부 할일 확인해 줘! 💛` 입니다.
  스마트폰 브라우저에서는 OS 공유 시트(카톡·피클 등)가 바로 뜨고(공유 시트를 그냥 닫으면 아무 안내도 없습니다),
  공유를 지원하지 않는 곳에서는 문구와 링크(`?room=` 포함)를 클립보드에 복사한 뒤 `확인 요청 문구를 복사했어요!` 하고 알려 줍니다. 복사된 문구는 카톡이나 피클에 붙여넣으면 됩니다.
- **메모** — 메모 시트(항목을 한 번 탭해 열리는 시트)에 적은 내용은 `todos/{id}/note` 에 저장되고 상대 화면에도 바로 보입니다.
  메모가 있는 항목은 할 일 줄 아래 `📝 메모 내용` 한 줄로 표시됩니다.
- **⇅ 큰 화면 순서 정리** — 카드 헤더의 `⇅` 를 **한 번 탭하면** 화면 전체가 순서 편집기로 열립니다.
  구분선·요일 칸 없이 미완료 할 일이 **한 줄로 쭉** 나열됩니다(예전 `dayGroup` 값은 화면에 쓰지 않고 그대로 둡니다).
  항목 오른쪽 `⋮⋮` 핸들을 길게 누를 필요 없이 바로 잡아 끌 수 있고(손가락은 `touch-action:none`), ▲▼ 버튼으로도 한 칸씩 옮깁니다.
  항목 **본문(제목·메모 미리보기)을 탭하면** 메인 화면과 같은 `📝 메모·수정` 시트가 그 위로 열려 제목·메모를 고칠 수 있고, 저장하면 순서 목록에도 바로 반영됩니다(뒤로가기는 메모 시트만 닫힘).
  각 줄의 **`오늘할일` 알약**을 누르면 그 자리에서 `todos/{id}/today` 가 바로 켜지고 꺼집니다(메인 화면과 같은 남색/연한 톤).
  끄는 동안에는 DOM 을 다시 그리거나 측정하지 않고 GPU `transform` 만 움직이며(밀려나는 행도 함께), 손을 뗀 순간에만 실제 순서를 반영합니다. `완료`를 누를 때 바뀐 `order` 만 한 번의 multi-path PATCH 로 보냅니다.
- **드래그로 순서 바꾸기(카드 안)** — 마우스는 항목을 끌면 바로, 휴대폰은 항목을 살짝 길게 눌러(280ms) 잡은 뒤 위아래로 끌면 순서가 바뀝니다.
  옆으로 미는 동작(|dx| > |dy|)은 스와이프로, 위아래로 움직이는 동작은 순서 바꾸기/스크롤로 나뉩니다.
  목록 끝에 가까워지면 목록이 저절로 스크롤됩니다. 바뀐 순서(`order`)는 바로 Firebase에 저장되어 상대 화면에도 실시간으로 반영됩니다.
- **📅 요일 지정 (이번만 · 매주 반복)** — `+ 할 일 추가` 와 `📝 메모·수정` 시트에 `📅 요일 지정` 칸이 있습니다.
  위쪽 `📌 이번만` / `🔁 매주 반복` 으로 방식을 고르고(새 할 일은 기본이 `📌 이번만`), 아래 `월 화 수 목 금 토 일` 일곱 알약을 눌러 요일을 고릅니다.
  `매주 반복` 일 때만 `매일 · 평일 · 주말` 빠른 선택이 보입니다(같은 빠른 선택을 한 번 더 누르면 해제). `요일 없음` 은 고른 요일을 모두 지웁니다.
  아무것도 고르지 않으면 예전과 같은 한 번짜리 할 일입니다(`지정한 요일 없음`).
  고른 요일은 `todos/{id}/repeatDays` = `[0~6]` (JS `getDay()` 기준, 0=일 … 6=토) 로 저장되고,
  **`📌 이번만` 은 `todos/{id}/repeatMode` = `'once'`** 로 표시합니다. `repeatMode` 가 없는 예전 항목은 그대로 **매주 반복**으로 읽히므로 100% 호환됩니다(매주 반복으로 저장할 때는 이 필드를 쓰지 않습니다).
  - **📌 이번만** — 고른 요일에만 `오늘할일` 이 켜지고(저장 순간 + 앱 열기·동기화 때 하루 한 번, `lastTodayAutoDate`), 체크해서 완료하면 그걸로 끝납니다. **다음 주 같은 요일이 와도 되살아나지 않습니다**(`applyRepeatResets` 가 `repeatMode:'once'` 를 건너뜁니다).
  - **🔁 매주 반복** — 체크하면 그날 완료로 넘어가고, **다음 반복 요일에 앱을 열면 자동으로 미완료로 되살아납니다**(`done: false` + `today: true`). 오늘이 반복 요일이고 `lastResetDate` 가 오늘보다 앞설 때 한 번만 쓰며, 두 기기가 동시에 열려 있어도 같은 값이라 결과가 같습니다.
  - 공통 — **오늘이 지정 요일이면 `오늘할일` 이 저절로 켜집니다**. 할 일을 추가하거나 `📝 메모·수정` 에서 요일을 저장하는 순간 바로 켜지고, 그 전에 만들어 둔 항목도 앱을 열거나 동기화될 때 하루 한 번만 켜집니다(`todos/{id}/lastTodayAutoDate` = `YYYY-MM-DD`). 그날 손으로 `오늘할일` 을 끄면 다시 켜지지 않습니다.
  - 목록 배지 — 왼쪽 동그라미에 요일을 1~3글자로 줄여 보여 줍니다(`매일`·`평일`·`주말`·`월수금`·`월+`).
    **오늘이 그 요일에 들어 있으면** `📌 금` 같은 이번만은 노란 배지(`#FDE68A`), `🔁 매주 금` 같은 매주 반복은 연보라 배지(`#E9E7FD`), **오늘이 아닌 요일이면** 이번만·매주 모두 연두 배지(`#DFF2DD` 바탕·`#1F5F2C` 글씨), `🗓️ 이후` 는 베이지 배지(`#ECE8DA`)입니다. 메인 목록과 순서 편집기가 같은 색을 씁니다.
- **🗓️ 이후** — `📅 요일 지정` 칸의 `🗓️ 이후` 버튼을 누르면 **요일도 반복도 없이 나중에 할 일**로 표시됩니다(`todos/{id}/later = true`).
  `이후` 는 요일·반복과 함께 쓰지 않아서, 누르면 고른 요일이 비워지고 `매주 반복` 상태에서 눌러도 `이번만` 의 이후로 바뀝니다. 다시 누르면 풀리고, 요일을 고르면 저절로 `📌 이번만` 으로 돌아옵니다.
  `이후` 항목은 **`오늘할일` 이 저절로 켜지지 않고** 반복으로 되살아나지도 않습니다(손으로 켜는 것은 그대로 됩니다). 목록 제목 아래 `🗓️ 이후` 배지로 보입니다.
- **실시간** — Firebase Realtime Database에 저장하고 SSE로 즉시 동기화합니다. 한쪽에서 체크하면 다른 쪽 화면이 바로 바뀝니다.
- **💬 서로의 한마디** — 카드 헤더 아래(진행 바 아래, 할 일 목록 위)에 슬림한 크림색 1줄 말풍선 바가 있습니다.
  비어 있으면 `💬 세은에게 한마디...` 처럼 보이고, 탭하면 작은 입력 시트가 올라옵니다(뒤로가기로 시트만 닫히고, `🗑 비우기`는 한 번 더 눌러야 비워집니다).
  적은 한마디는 `say/{seeun|changyu}` = `{text, at}` 로 저장되고 SSE 로 상대 화면에 바로 보입니다.
- **마지막 접속 시간** — 앱 맨 위 헤더의 알약에 두 사람의 마지막 접속이 한 줄씩 보입니다(`방금` / `오늘 19:05` / `어제 22:10` / `11/18 19:05`, 기록이 없으면 `기록 없음`).
  앱을 열 때와 백그라운드에서 돌아올 때 `lastSeen/{seeun|changyu}` 에 시각을 남기고(보고 있는 동안 90초에 한 번), 상대가 들어오면 SSE 로 바로 반영됩니다.
  같은 방 링크·비밀번호를 둘이 같이 쓰므로 **기기마다 한 번만** `이 기기는 누구인가요? 👩🏻 세은 / 👨🏻 찬규` 를 고르게 하고(`localStorage` 의 `bubu.me.v1`),
  바꾸려면 헤더의 접속 시간 알약을 누르면 다시 열립니다.
- **뒤로가기는 시트만 닫기** — 안드로이드에서 뒤로가기를 눌러도 앱이 꺼지지 않고, 열려 있는 시트(`할 일 추가`·`메모 · 수정`·`✅ 완료됨`·`⇅ 순서`)만 닫힙니다.
  시트를 열면 `history.pushState({appModal:true})` 로 히스토리를 하나 쌓고 `popstate` 에서 그 시트만 닫으며,
  X·배경·저장으로 직접 닫았을 때는 쌓아 둔 히스토리를 `history.back()` 으로 정리합니다.
- **알림 토스트는 문제 있을 때만** — 할 일 추가·삭제·완료·오늘할일·메모·한마디 저장·운동 체크처럼 정상적으로 끝난 동작에는
  화면 위 토스트를 띄우지 않습니다. 저장 실패(`저장하지 못했어요`), 입력이 필요할 때(`할 일을 적어 주세요`),
  연결 오류(`연결을 확인해 주세요`), 지울 내용이 없을 때처럼 **실제 문제가 있거나 사용자가 뭔가 해야 할 때만** 짧게 알려 줍니다.

## 파일

- `index.html` — 화면·동작 전부 (한 파일)
- `wo/*.jpg` — 운동 탭 유튜브 섬네일 11장
- `sw.js` — 오프라인 캐시 서비스워커 (`bubu-v40`). 화면은 네트워크 우선, 나머지는 캐시 우선
- `manifest.webmanifest`, `icon-*.png` — 홈 화면 설치용

## 손보는 법

`main` 브랜치를 고쳐 푸시한 뒤 같은 내용을 `gh-pages` 로도 올리면 1~2분 안에 반영됩니다.
화면 캐시가 남아 있으면 서비스워커 캐시 이름(`bubu-v40`)을 한 단계 올려 주세요.
